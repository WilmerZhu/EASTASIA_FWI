# S1 模型库的收集范围与收录标准

模型来自公开文献、IRIS地球模型协作中心（EMC）、作者主页与论文补充材料等渠道，收录遵循三条标准：模型的水平范围与本文研究区有实质性重叠；速度场以数字形式公开发布，而非仅有图件；随模型提供可追溯的参数化方式与一维参考模型信息，以便复核。时间下限取2018年，一是此前的多数区域模型已被同一团队的后续版本取代，二是早期模型往往缺少机器可读的分发格式。

按覆盖范围与水平分辨率，模型库分为三层。第一层为覆盖岩石圈至过渡带乃至上地幔底部的准全域模型，包括FWEA23、EARA2024（水平分辨率约0.25°，深度0—1000 km）和SinoScope1.0（约1.0°，深度延伸至下地幔），是唯一能在整个研究区上逐点比较的一组，承担正文的全域统计。第二层为岩石圈尺度的区域模型，如FWEA18、CSRM1.0、USTClitho2.0等，深度多不超过150 km，水平分辨率0.25°—0.5°。第三层为局部高分辨率模型，如川滇地震科学实验场、青藏、东北与华南等地的地壳—上地幔模型，网格可细至0.05°—0.1°，但覆盖面积小、深度浅。第二、三层模型彼此空间范围不重合，深度区间也与第一层不匹配，无法纳入同一个全域相似性矩阵，正文中仅用作局部结构的对照参考。

# S2 原始格式与参数化的异质性

模型库在技术属性上高度异质，这是标准化流程必须首先处理的问题。分发格式包括NetCDF、HDF5、GeoCSV、按深度切片的文本文件乃至电子表格；参数化有各向同性与径向各向异性之分，后者给出的是vsv、vsh而非单一Vs；一维参考模型分别取PREM、ak135或STW105；深度基准也不统一，部分模型自地表起算，部分自海平面起算，个别模型的深度坐标还带有固定偏移。上述任何一项若不先行统一，都会以系统性偏移的形式混入模型间比较，并被误读为真实的结构差异。

# S3 标准化处理流程

**统一数据格式**　全部模型转换到符合CF约定的NetCDF：维度顺序为(latitude, longitude, depth)，速度单位km/s，深度单位km且以向下为正，密度单位g/cm³。参数名统一为vp、vs、vpv、vph、vsv、vsh、rho、eta。

**深度基准校正**　SinoScope1.0原始深度为20—2820 km，平移−20 km后与地表起算的其他模型对齐。其余模型的深度基准逐一核对模型说明文件后确认，未作平移。

**各向异性参数的处理**　各向异性模型若仅提供vsv、vsh，则各向同性Vs取二者的适当平均。正文的相似性与聚类分析均在各向同性Vp、Vs上进行，径向各向异性参数本身不参与比较。

**缺失参数的补全**　缺失Vp或密度时，地壳深度采用Brocher(2005)经验关系补全，地幔深度采用扰动比例（dlnVp ≈ 0.5 dlnVs，dlnρ ≈ 0.3—0.4 dlnVs）。两套关系的适用深度不同，不可混用——Brocher关系由地壳岩石实验数据标定，外推至地幔并无依据。需要强调的是，正文重点对比的SinoScope1.0、EARA2024与FWEA23均具备原生的Vp与Vs，不经过任何补全，因此正文中Vp的结构相似性统计不受该规则影响。

**统一分析域**　所有模型对共用同一分析域：地理范围取全部模型覆盖的交集（约10°—55°N、80°—150°E），水平网格取模型库中最粗的分辨率（正文三模型为1.0°），并以有效交集掩膜剔除无数据节点，逐层有效覆盖率约0.90。
