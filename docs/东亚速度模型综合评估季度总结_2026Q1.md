# 东亚课题 2026 年第一季度总结（草稿）

---

## 以往工作回顾

东亚地区记录了洋陆俯冲、陆陆碰撞、陆内火山、增生造山、岩石圈形变等复杂构造过程，是研究陆内构造、克拉通破坏、地势隆升及古环境古气候巨变的天然实验室。随着近年来地震观测数据数量与质量的飞跃式提升，以及地震学成像和反演技术的蓬勃发展，众多学者围绕不同的地震波数据和多样化的反演方法，建立了丰富的多空间尺度三维速度模型。然而，伴随着速度模型数量的激增和构建方法的多元化，针对不同模型的一致性、差异性、适用性等的系统性评价工作实际上才刚刚起步。构建科学化、系统化且可量化的模型对比和评价体系，无疑是推动未来速度模型改进优化和可靠性提升、揭示地球深部精细结构不可或缺的重要支撑工作。

过去一年，我们主要聚焦于东亚地区岩石圈速度模型的收集、标准化与对比评估，取得了以下进展。一是建立综合模型数据库：系统收集整理了过去十几年来针对东亚地区（特别是中国大陆）发布的三十余个三维地壳、岩石圈和地幔速度模型，涵盖体波走时、面波、接收函数、全波形反演等多种成像方法，模型库持续更新。二是开发模型评估框架：构建了涵盖模型空间与数据空间的双路径评估体系，为模型一致性、差异性及适用性分析提供方法和工具基础。三是以 SinoScope1.0、FWEA23 和 EARA2024 三个近期的全波形反演模型作为典型测试，开展了深入的对比评估研究。在模型空间，我们建立了基于聚类分析和结构相似性算法的评估工具库。水平切片对比显示，三个模型在浅部地壳至上地幔深度均清晰展现出东亚地区的主要构造特征——青藏高原及周边造山带的高速异常、西太平洋边缘海盆地的低速异常、俯冲带的高速板片结构；但随着深度增加，模型间差异逐渐增大，特别是在地幔过渡带和下地幔顶部，速度分布模式存在比较显著的分歧。聚类分析揭示，在岩石圈和俯冲板片尺度上，模型间存在显著的一致性特征，能清晰识别稳定克拉通与造山带、高原、盆地等核心构造，但在更小尺度细节和深度界面刻画上仍存在差异。结构相似性指数（SSIM）显示，尽管整体模型相似性较好，但在软流圈和地幔过渡带等不同深度区域，模型间的差异更为显著，揭示了速度模型对复杂结构和过程的约束存在较大不确定性。四是着手设计和收集东亚地区高质量地震台站和事件波形作为标准化检验数据库，为后续数据空间波形评估奠定基础。上述工作为今年的开源项目建设和正演测试提供了重要铺垫。

## 本季度主要进展

本季度工作主要聚焦于**开源项目体系建设**、**多模型正演测试与任意模型接口**以及**模型融合方法应用**，力求为东亚地区速度模型综合评估提供可复现、可扩展的工具链和标准化流程。2 月上旬，东亚岩石圈模型标准化研讨会在南方科技大学举行，会议倡导构建开放、可迭代、贡献可溯的标准模型平台，建立统一的模型评价框架与数据标准。本课题在模型标准化、双路径评估框架和开源工具链建设等方面的进展与会议方向高度契合，既为项目推进赢得了更广泛的共识支撑，也为后续参与协作、推动成果共享创造了有利条件。

### 一、开源项目建立

在去年模型空间与数据空间双路径评估框架的基础上，本季度完成了 EASTASIA-FWI（别名 SMART-py，即地震模型评估与融合工具箱）开源项目的体系化建设。项目以 GitHub 仓库形式托管，面向东亚地区全波形成像与速度模型综合评估的完整工作流，采用模块化架构，便于研究者按需使用和二次开发。

项目涵盖五大功能模块：数据准备模块负责台站查询、GCMT 事件处理、波形下载与预处理、速度模型标准化等；模型空间分析模块负责多模型对比、聚类分析、结构相似性分析等；数据空间模拟模块负责谱元法参数设置、模型格式转换、正演计算管理等；模型融合模块以贝叶斯模型平均（BMA）为核心，并探索 SDL 耦合字典学习、PGM 概率图模型等先进融合方法；可视化模块负责基础地图、事件与台站分布、速度模型对比等图件生成。各模块采用统一的配置管理，研究区域、项目目录、日志系统等均可集中配置；速度模型采用双区域 NetCDF 输出，既保留各模型完整覆盖范围，又提供多模型共同覆盖区域，便于聚类与公平对比。项目还提供完整文档、环境配置说明和 Web 静态展示界面，支持速度模型对比、相似性分析等结果的在线浏览与分享。

截至目前，项目已支持三十余个东亚地区速度模型的标准化处理与对比分析，涵盖体波走时、面波、接收函数、全波形反演等多种成像方法构建的模型，模型库持续更新。开源项目的建立，为东亚速度模型综合评估工作的可复现性、可扩展性和社区协作奠定了坚实基础。

### 二、各模型正演测试与任意模型接口

基于谱元法的全波形正演模拟是评估速度模型可靠性的重要手段。通过比较实际观测与理论合成地震波形，可直接量化模型对波形的拟合能力，为模型排序和初始模型优化提供依据。本季度的核心攻关方向是构建**任意公开三维速度模型**的正演模拟与波形检验接口——使研究者能够对任意标准化模型进行波形正演与检验，无需依赖原作者提供的专用数据，从而支持东亚地区更多速度模型的系统性评估。

多数公开速度模型以 NetCDF 或 CSV 等规则网格格式发布，而谱元法正演需要 GLL 格式。我们开发了从规则网格到 GLL 网格的格式转换工具，实现坐标转换、域内外插值、各向同性与横向各向同性参数支持、单位换算等功能，并可与参考结果进行自检对比。在曙光 Slurm 集群上建立了完整正演流程，包括编译、网格生成、格式转换、上传与求解的协作步骤；考虑到集群与本地环境的差异，格式转换在本地完成，网格生成与求解在集群完成，形成了清晰的分工与文档化流程。FWEA23 因有原作者参考结果可对比验证，被选为首个测试用例；编写了服务器端操作文档，便于后续复现和扩展至 EARA2024、SinoScope1.0 等模型。当前在区域配置与软件兼容性方面仍存在一些技术难点，正在逐步排查推进，该接口的稳定实现是后续批量正演与波形评估的关键前提。

### 三、模型融合工作

多模型融合旨在综合利用不同模型的优势区域和约束信息，生成研究区域的集成模型，为全波形反演提供更优的初始模型。项目采用"双空间协同"的技术路线，模型融合作为衔接模型空间分析与数据空间验证的关键环节，其方法选择直接影响初始模型的质量和反演收敛效率。

本季度，模型融合模块以**贝叶斯模型平均（BMA）**为核心得到完善和应用。BMA 基于一致性或波形拟合权重计算各模型后验概率，得到加权融合模型及后验不确定性，并输出主导模型空间分布、权重熵等可视化结果，为理解不同模型在不同区域的贡献提供直观依据。相比简单平均，BMA 能够根据模型在数据空间的表现动态调整权重，具有更好的统计理论基础。此外，项目正在探索 **SDL 耦合字典学习**和 **PGM 概率图模型**等先进融合方法：SDL 旨在让粗分辨率模型继承高分辨率模型的细节特征，实现分辨率增强；PGM 则通过马尔可夫随机场建模空间相关性，在边界区域实现平滑过渡。这些方法有望为构建高质量初始模型提供更多选择，为后续新一代东亚岩石圈模型 SEAM 1.0 的构建奠定基础。

---

### 四、下一步工作

一是继续排查谱元法区域配置兼容性，争取在曙光集群上稳定完成 FWEA23 全流程正演，并在此基础上扩展至 EARA2024、SinoScope1.0 等模型，形成多模型正演评估的标准化流程。二是建立标准化检验数据库，开发波形拟合指标（到时差、振幅差、互相关系数等），实现数据空间模型排序，将模型空间与数据空间的评估结果相结合，为模型可靠性提供更全面的量化依据。三是将 BMA 及 SDL、PGM 等融合方法产出的初始模型作为基底，结合大规模波形数据开展全波形反演，推进新一代东亚岩石圈模型 SEAM 1.0 的构建，为东亚地区深部结构研究和地球动力学解析提供新一代标准模型。
